# Juego botones

Proyecto Unity de una tienda mágica de botones en primera persona.

## Abrir el proyecto

- Usar Unity **6000.6.5f1**.
- Clonar o descargar este repositorio y agregar su carpeta desde Unity Hub.
- Abrir **Assets/Scenes/TallerHabitacion.unity** y presionar Play.
- Unity regenerará Library durante la primera importación.

La escena actual incluye la galería, las paredes de lino y los ocho apliques opalinos. Las escenas y generadores antiguos corresponden a versiones anteriores; no ejecutarlos para reconstruir la escena actual.

Controles: clic para controlar, WASD para caminar, mouse para mirar, Shift para caminar rápido, Escape para liberar el cursor y Home para volver al inicio.

Para compilar, seleccionar TallerHabitacion como escena inicial en Build Profiles.
